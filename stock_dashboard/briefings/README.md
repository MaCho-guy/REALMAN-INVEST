# 증시 브리핑 넣는 곳

다른 대화에서 쓴 브리핑을 이 폴더에 **날짜 파일명**으로 저장하면
대시보드 매크로 탭 맨 위에 올라오고, 요약 탭에 한 줄로 표시됩니다.

## 파일명

```
briefings/2026-11-10.md      ← 마크다운
briefings/2026-11-07.html    ← HTML (아티팩트에서 복사한 경우)
```

`YYYY-MM-DD` 형식이어야 읽습니다. 날짜를 **파일명에서** 읽기 때문에
meta 파일이 따로 없습니다 — 파일을 복사해 새 브리핑을 쓸 때 날짜 고치는 걸
잊어서 지난주 글이 최신으로 올라오는 일을 막으려는 것입니다.

이 README.md 는 날짜 형식이 아니므로 브리핑으로 읽히지 않습니다.

## 앞머리 (선택)

```markdown
---
title: 11월 2주 증시 브리핑
sources:
  - https://www.federalreserve.gov/...
  - https://ir.micron.com/...
---

본문을 마크다운으로 씁니다.
```

- `title` 이 없으면 본문 첫 제목(`#`) 줄을 제목으로 씁니다.
- `sources` 는 `http://` 또는 `https://` 로 시작하는 주소만 링크가 됩니다.
  나머지는 제외하고 화면에 그 사실을 적습니다.
- 앞머리 전체를 생략해도 됩니다.
- HTML 파일에는 앞머리를 쓰지 않습니다. 아티팩트 원문을 그대로 넣는
  용도라 손대지 않습니다.

## 오래됨 표시

7일이 지나면 "N일 전 글입니다 — 지금 시장을 설명하지 못할 수 있습니다"
경고가 붙습니다. 분석 문서(90일)보다 짧게 잡은 이유는, 시장 브리핑은 한 주가
지나면 현재 상태를 설명하지 못하기 때문입니다.
